# Nakshatra Chakram v1.0.1

Local Vedic birth chart and nakshatra wheel. No signup — data stays on your computer.

## Download

| Platform | File |
|----------|------|
| **macOS** | `nakshatra-chakram-1.0.1-macos.dmg` |
| **Windows** | `nakshatra-chakram-1.0.1-windows.exe` |

Get both from the [landing page](https://avinashpeyyety.github.io/nakshatra/#downloads).

## macOS

1. Open the `.dmg` → drag **Nakshatra Chakram** to **Applications**.
2. Launch from **Applications** (right-click → **Open** if Gatekeeper blocks).
3. Requires **Python 3.10+** on first run.

## Windows

1. Download and run `nakshatra-chakram-1.0.1-windows.exe`.
2. If SmartScreen warns: **More info → Run anyway**.
3. Browser opens at http://127.0.0.1:8000 when ready.

## Changes in v1.0.1

- **No pre-loaded charts** — user data stored in Application Support, not inside the app bundle.
- Fresh install starts with an empty chart form (no dev chart from browser cache).
- macOS `.dmg` + Windows `.exe` hosted on the landing page only.
