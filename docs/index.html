Why local

  • No account or signup — install and run in your browser at 127.0.0.1
  • Birth charts saved on your machine, not our servers
  • Swiss Ephemeris sidereal calculations (Lahiri and other ayanamsas)
  • Interactive nakshatra wheel, dashas, yogas, and gochara

Install

macOS: use the macOS download above. Open the .dmg, drag Nakshatra Chakram to Applications, then launch from Applications. Requires Python 3.10+ on your Mac; first launch installs dependencies (a few minutes).
Windows: use the Windows download above and run the .exe (browser opens at http://127.0.0.1:8765).
Note: the installed app uses port 8765; local development still uses 8000.
If macOS blocks the app: right-click → Open, or System Settings → Privacy & Security → Open Anyway. If Windows SmartScreen warns: More info → Run anyway.
