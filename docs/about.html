About Nakshatra Chakram

Nakshatra Chakram is a local-first desktop app for Vedic (Jyotish) birth chart work. You enter birth date, time, and place; the app computes a sidereal chart with Swiss Ephemeris and shows it in your browser at 127.0.0.1. No account, no cloud storage of chart data.

What it is for

Students and practitioners who want a private wheel, dasha timelines, classical yoga summaries, and transit (gochara) context — without uploading birth details to a website. Everything runs on your computer; saved charts stay in your user data folder.

Features (Chart edition)

Birth chart & wheel

  • Sidereal positions from Swiss Ephemeris (Lahiri ayanamsa by default; Raman and Krishnamurti also available)
  • Interactive nakshatra wheel — lagna at top, planets by longitude, retrograde and dignity cues
  • Offline place lookup (bundled city catalog); optional online geocoding is not required for install
  • Save and switch between multiple named charts (stored locally)

Dasha

  • Vimshottari — current Maha / Antar / Pratyantar, balance at birth, past and upcoming periods
  • Jaimini Chara (sign-based) — direction from lagna, 12-sign timeline

Yogas

  • Automatic detection of common yogas (e.g. Gajakeshari, Pancha Mahapurusha variants, Kemadruma, Neecha Bhanga Raja, Parivartana, and others)
  • Short interpretations in the Yogas tab

Gochara (transits)

  • Current planetary positions and ranked transit alerts
  • Context for the active saved chart (Sade Sati, sign changes, major aspects)
  • Dasha-period notes including Jupiter / Saturn / Rahu ingresses and double-transit windows

Under the hood (summary)

  • Divisional vargas, ashtakavarga, shadbala, Jaimini karakas — available to the calculation engine and exports
  • Combustion and retrograde flags use traditional orbs

Privacy & data

  • No signup or license server
  • Chart library and settings on disk (macOS: ~/Library/Application Support/Nakshatra Chakram/)
  • The app does not send your birth data to us; there is no central chart database
  • Educational software — not a substitute for professional advice

Requirements

  • macOS: Python 3.10+ from python.org or Homebrew (system Python 3.9 is not supported). First launch installs Python packages locally.
  • Windows: standalone .exe (no separate Python install)
  • Network used only for your browser talking to the local server (127.0.0.1:8765)

What this release is not

  • Not a hosted astrology service — you download and run it locally
  • Not notarized by Apple — you may need right-click → Open on first launch
  • Source code for development is maintained separately; this site distributes installers only
