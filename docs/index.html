About

Nakshatra Chakram is a local-first desktop app for Vedic (Jyotish) birth chart work. Enter birth date, time, and place; the app computes a sidereal chart with Swiss Ephemeris and shows it in your browser at 127.0.0.1. No account, no cloud storage of chart data.

Built for students and practitioners who want a private wheel, dasha timelines, classical yoga summaries, and transit (gochara) context — without uploading birth details to a website. Everything runs on your computer; saved charts stay in your user data folder.

Features

Two builds: Lite (calculations only) and Advisor (Lite + local Ornith 9B full-chart report and Q&A).

Wheel

  • Sidereal positions from Swiss Ephemeris (Lahiri ayanamsa by default; Raman and Krishnamurti also available)
  • Interactive nakshatra wheel — lagna at top, planets by longitude, retrograde and dignity cues
  • Offline place lookup (bundled city catalog)
  • Save and switch between multiple named charts (stored locally)

Dasha

  • Vimshottari — current Maha / Antar / Pratyantar, balance at birth, past and upcoming periods
  • Jaimini Chara (sign-based) — direction from lagna, 12-sign timeline

Yogas

  • Automatic detection of common yogas (e.g. Gajakeshari, Pancha Mahapurusha variants, Kemadruma, Neecha Bhanga Raja, Parivartana, and others)
  • Short interpretations in the Yogas tab

Gochara (transits)

  • Current planetary positions and ranked transit alerts
  • Context for the active saved chart (Sade Sati, sign changes, major aspects)
  • Dasha-period notes including Jupiter / Saturn / Rahu ingresses and double-transit windows

Under the hood

  • Divisional vargas, ashtakavarga, shadbala, Jaimini karakas — available to the calculation engine and exports
  • Combustion and retrograde flags use traditional orbs

Privacy & data

  • No signup or license server
  • Chart library and settings on disk (macOS: ~/Library/Application Support/Nakshatra Chakram/)
  • The app does not send your birth data to us; there is no central chart database
  • Educational software — not a substitute for professional advice

This site is documentation and installers only — not a hosted chart service. Source: github.com/avinashpeyyety/nakshatra.

Install

macOS: use the macOS download above. Open the .dmg, drag Nakshatra Chakram to Applications, then launch from Applications. Requires Python 3.10+ from python.org or Homebrew (macOS system Python 3.9 is not enough). First launch installs dependencies (a few minutes).

Windows: use the Windows download above and run the .exe (browser opens at http://127.0.0.1:8765). No separate Python install.

Note: the installed app uses port 8765; local development still uses 8000. Network is only your browser talking to the local server.

If macOS blocks the app (not notarized): right-click → Open, or System Settings → Privacy & Security → Open Anyway. If Windows SmartScreen warns: More info → Run anyway.
