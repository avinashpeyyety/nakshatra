# Nakshatra Chakram v1.0.2

Local Vedic birth chart and nakshatra wheel. No signup — data stays on your computer.

## Download

| Platform | File |
|----------|------|
| **macOS** | `nakshatra-chakram-1.0.2-macos.dmg` |
| **Windows** | `nakshatra-chakram-1.0.2-windows.exe` |

Get both from the [landing page](https://avinashpeyyety.github.io/nakshatra/#downloads).

## macOS

1. Open the `.dmg` → drag **Nakshatra Chakram** to **Applications**.
2. Launch from **Applications** (right-click → **Open** if Gatekeeper blocks).
3. Requires **Python 3.10+** on first run.
4. The app opens at **http://127.0.0.1:8765** (not port 8000).

## Windows

1. Download and run `nakshatra-chakram-1.0.2-windows.exe`.
2. If SmartScreen warns: **More info → Run anyway**.
3. Browser opens at **http://127.0.0.1:8765** when ready.

## Changes in v1.0.2

- **Installed app uses port 8765** — no longer attaches to a dev server already running on port 8000.
- Same as v1.0.1: no pre-loaded charts; user data in Application Support / AppData.
