# Nakshatra Chakram v1.0.0

Local Vedic birth chart and nakshatra wheel. No signup — data stays on your computer.

## Download

| Platform | File |
|----------|------|
| **macOS** | `nakshatra-chakram-1.0.0-macos.dmg` |
| **Windows** | `nakshatra-chakram-1.0.0-windows.exe` |

**Download installers from the [landing page](https://avinashpeyyety.github.io/nakshatra/)** — only the `.dmg` and `.exe` links there. We do not use GitHub Releases (GitHub adds unavoidable “Source code” zip/tar.gz on every public release).

## macOS

1. Open the `.dmg` → drag **Nakshatra Chakram** to **Applications**.
2. Launch from **Applications**.
3. If blocked: **right-click → Open**.
4. **Python 3.10+** required on first run (installs dependencies into the app’s venv).

## Windows

1. Download and run `nakshatra-chakram-1.0.0-windows.exe`.
2. If SmartScreen warns: **More info → Run anyway** (unsigned build).
3. Browser opens at http://127.0.0.1:8000 when the server starts.

## Included

- Sidereal chart, nakshatra wheel, dashas, yogas, gochara
- Saved charts (local SQLite)
- Offline place lookup
